🧠Fake News & Deepfake Detector

➡️ Overview

This project is a multimodal AI system that detects fake news using Natural Language Processing (NLP) and analyzes images for deepfake patterns using computer vision.

🔧 Tech Stack

- Python
- Streamlit
- Transformers
- OpenCV
- NumPy

✅Features

- Detect fake news from text input
- Analyze images for possible deepfake manipulation
- Simple and interactive web interface

▶️ How to Run

pip install -r requirements.txt
streamlit run app.py
